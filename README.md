# Motion-Platform
Project repository 

A 3 Degree of freedom motion simulator used to simultaneously simulate the visuals in VR headset. It is used in gaming, training of pilots etc. It significantly reduces the cost of development as everything is simulated in VR. And it also improves safety. The operator sitting on the motion platform feels the movement in real time as he/she are simulating in VR.
The complete project from hardware to software, R&D was done by us.

motion platform which is designed to handle a dynamic load of 90 kgs. 
It is a prototype developed for R&D purposes for Parallax Labs. 
It is used to simulate the movement in real time, as the joystick is moved by the operator. 
The operator experiences the simulation shown in the laptop in a virtual reality headset in 360* degrees while the operator is sitting on the motion platform. 
This as a product is used by airlines to train their pilots in a simulation based safe environment
